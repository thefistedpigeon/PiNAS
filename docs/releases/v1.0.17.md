# PiNAS v1.0.17 — Storage and Media Server Button Consistency

**Development candidate:** standardises the new Storage and MiniDLNA controls without changing their underlying operations.

- Storage → **Scan file types** uses the supplied scan SVG.
- Media Server → **Start**, **Stop**, **Restart**, **Restart scan**, **Rebuild library**, **Create media library**, **Add folder**, **Grant DLNA read access** and **Upload media** use the supplied SVG artwork.
- All button glyphs are fixed at 22×22 px, use `currentColor` and are aligned with standard 8px text spacing. They inherit the outline-button hover text/icon colour.
- The shared `.btn.outline:hover:not(:disabled)` rule applies the PiNAS accent fill, border and white foreground to new and older outlined buttons.
- **Save settings** and **Refresh** remain text-only and use the standard button hover behaviour.
- No filesystem, account, Samba, MiniDLNA service or privileged helper logic was changed.

Before release: check the button glyphs at normal and small font sizes, both light and dark themes, keyboard focus, disabled states, and hover/tap. Build and JavaScript syntax checks are run in GitHub Actions.
