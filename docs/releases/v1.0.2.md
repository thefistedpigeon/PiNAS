# PiNAS v1.0.2 — regular-user logout hotfix

## Fixed

Standard NAS users could not sign out of the WebUI. The shared browser-side logout function sent `POST /api/logout`, but the API handler handled that route only after its administrator-only permission guard, resulting in `403 Administrator access required`.

The logout route now executes **after session/CSRF verification but before administrator-only authorization**, so both admin and standard users can end their own sessions safely.

## Validation

- Added HTTP-handler tests for both administrator and standard-user logout
- Asserted session invalidation and cookie expiration
- Asserted invalid CSRF tokens remain rejected
- Rebuilt the standalone `pinas.py` to version 1.0.2

This hotfix does not change NAS data handling, file operations or privileged helpers.
