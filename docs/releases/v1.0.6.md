# PiNAS v1.0.6

PiNAS v1.0.6 is the next official release following v1.0.3. It includes the tested v1.0.4 and v1.0.5 development milestones, alongside the v1.0.6 dashboard and updater improvements.

## Highlights

### Reliability and recovery (v1.0.4)
- Export a password-protected administrator-authorised JSON recovery manifest with portable UI preferences, account display names and a read-only inventory of NAS users/shares.
- Restore strictly validated device preferences and display names without changing NAS disks, existing Samba accounts or filesystem content.
- Stage CLI installer replacements atomically and retain a previous application bundle for recovery if module extraction fails.

### Storage safety (v1.0.5)
- Warn when PiNAS-managed UUID data mounts are missing, unexpectedly unmounted, or mounted with an unexpected filesystem.
- Display degraded mdadm RAID warnings prominently on relevant pages.
- Verify current hardware eligibility immediately before a privileged storage-adoption operation.
- All new checks remain non-destructive; no automatic disk repair, formatting or RAID changes were introduced.

### Dashboard and interface (v1.0.6)
- Remove load average from the System Health card.
- Move SMART status and temperature from the Storage page into each drive's **Overview → Storage at a glance** entry.
- Check SMART on entering Overview or by using the **Check disk health** action, without background SMART polling. Unsupported drives/adapters are reported as unavailable.
- Refine card spacing and use consistent accent-colour hover behaviour and supplied SVG icons for **Check disk health**, **Install selected update**, and NAS Service Health **Refresh**.

### Application updater (v1.0.6)
- Detect when the PiNAS web service has restarted after a successful update, including reinstallation of the same version, and automatically reload the interface when it reconnects.
- The service restart may require signing in again. When upgrading *from* an older release, a one-time manual browser refresh may still be needed because the old page is running the previous updater code.

## Installation / upgrade

Download **pinas.py** from the assets attached to this GitHub release. Use it for a fresh installation or upload it under **Settings → Update PiNAS** on an existing installation. Verify the optional `pinas.py.sha256` checksum before installing when practical. Only install files from a trusted source.

Updates preserve PiNAS configuration and mounted NAS data, but independent backups remain important. The JSON configuration export is not a complete data or Samba-password backup.

## Known limitations

- **MiniDLNA / Media Server** remains excluded until its installation issues can be investigated on a freshly rebuilt test Pi.
- RAID creation, formatting and other destructive operations remain disabled; existing arrays can be monitored.
- Raspberry Pi EEPROM firmware checking is available, but installation through the UI is not.
- SMART health and temperature depend on hardware and USB adaptor support; unavailable values do not mean a disk has passed a health check.
- The PiNAS application is intentionally lightweight and focused on Raspberry Pi OS Lite; no Docker or heavyweight application platform is included.

## Validation

The v1.0.4, v1.0.5 and v1.0.6 development branches were reviewed, tested on Raspberry Pi hardware and merged to `main`. Release automation re-runs the bundle consistency and regression checks before publishing the release artifact.
