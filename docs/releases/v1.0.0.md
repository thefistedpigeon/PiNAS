# PiNAS v1.0.0

**First official release candidate for publication** — Raspberry Pi-focused, lightweight NAS management via a browser and a standalone Python installer.

## Highlights

- **Overview:** Full-width per-drive usage bars, compact disk/share/user counters, CPU activity history, memory and temperature monitoring, system and service health.
- **Storage:** Drive discovery, ext4/XFS/Btrfs awareness, persistent mount management and storage workflows. Basic mdadm RAID support with hardware-aware availability.
- **File sharing:** Samba users, SMB shares, access controls and a web file explorer for authorised NAS users.
- **System updates:** APT update checking/installation, update schedules and read-only Raspberry Pi EEPROM firmware status checking on supported models.
- **Settings:** Wider collapsible-by-default sections, Light/Dark appearance, CPU monitoring, security, login background and administration.
- **Self-updating:** Upload a trusted standalone `pinas.py` through Settings → Update PiNAS, with administrator verification, package checks and best-effort application rollback.
- **Modular development:** `src/pinas/` source sections and a standard-library release builder produce one self-extracting `pinas.py`.

## Installation

Download `pinas.py` from the v1.0.0 release and run:

```bash
sudo python3 pinas.py --install --lan
```

Then open `https://<raspberry-pi-ip>:8765` on the local network. A self-signed certificate warning is expected initially.

For an existing installation with dependencies already present:

```bash
sudo python3 pinas.py --install --lan --skip-packages
```

If updating through the WebUI, upload this exact `pinas.py` under Settings → Update PiNAS. Keep a backup of important NAS data and configuration.

## Build and verification

```bash
python3 tools/build_release.py --check
python3 -m py_compile pinas.py
```

On the target Pi:

```bash
systemctl is-active pinas.service
ls -lah /opt/pinas/modules/
```

## Notes and limitations

- PiNAS targets Raspberry Pi OS Lite and related Debian-based systems; Pi 3B/3B+ are baseline devices.
- EEPROM firmware installation/flashing is **not** included; status checking only.
- The Media Server page is deferred pending a reliable lightweight implementation. No container engine is bundled.
- Modules are logically separated source sections, not yet independently imported runtime packages.
- A self-update SHA-256 comparison verifies transport integrity, not the authenticity of the publisher; install only trusted releases.
- Any format, wipe, RAID or permission change can affect data. Independent backups remain essential.
- Behaviour depends on hardware and OS version; this release should receive a final smoke test before public promotion.
