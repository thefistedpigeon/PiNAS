# PiNAS v1.1.4 — Shares Page Consistency

Release date: 2026-11-07

## Changes

This is a **UI-only consistency release** for the Shares page; the backend user, share, ACL, folder deletion, and update-history operations are unchanged.

### Create Share
- Keep the existing folder-plus SVG icon.
- Replace icon-only presentation with the standard **Create Share** text-and-icon button.
- Retain the current create-share wizard and click handler.

### Actions for each existing share

The action order is now exactly:

1. **Edit Share** — existing edit icon plus a visible text label.
2. **Stop Sharing** — existing label plus the newly supplied folder-with-blocked-sharing icon.
3. **Repair Access** — existing label plus the newly supplied crossed-tools icon.
4. **Delete Folder** — existing folder-with-X icon plus label; remains the visibly destructive, red-styled operation.

All four use the central `button-with-icon` class and consistent 22-pixel icon dimensions and hover styling, except **Delete Folder**, which preserves its red hover colour. Button labels, tooltips, disabled state, and existing click handlers remain usable.

Legacy **Move folder** is preserved for older shares under `PiNAS Shares` but is presented separately from the four main actions. The share entry layout wraps on narrower screens to accommodate the longer buttons.

## Safety and compatibility

- **Stop Sharing** preserves the share folder and files; **Delete Folder** continues to require administrator password, typed share name, and confirmation before irrevocable deletion.
- Existing security checks and backend operations from v1.1.3 are unchanged.
- No changes to users, Samba configuration logic, ACLs, disks, RAID, logs, SMART or session management.
- Version advances to **1.1.4** and the standalone `pinas.py` update package is rebuilt with the same embedded fonts.

## Verification

The PiNAS quality workflow validates the source, standalone bundle and all regressions. New v1.1.4 tests verify button order, precise icon paths, shared styles and preserved click handlers. As always, visually check the Shares page at both desktop and mobile widths on a Raspberry Pi after upgrade.
